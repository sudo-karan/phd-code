### A check of the round's own fixes: three gaps in the wrapper's B4 and B5 fixes

A review of this round's changes at `0100191` (five areas, each finding checked by a second,

  SIGINT) fails before with `assert ([], ['cfg_a'], []) == ([], [], ['cfg_a'])`. The harness's
  runner can now hold after it sends its Drive exports.
- **A save cut short.** The state file, which B4's resume reads first, was rewritten in place, so a
  save cut short (a full disk, a crash) could leave it empty or half written, and every later start
  of the label then stopped on it. It is now written beside itself, flushed to disk and moved over
  the old one (`os.replace`). The test (`test_a_save_cut_short_leaves_the_earlier_state_whole`;
  every write of the state file stops halfway, as on a full disk) fails before with
  `json.decoder.JSONDecodeError`.
- **A signal handler that could wait forever.** The handler set a `threading.Event`, whose lock
  `Event.wait` holds for a moment on each call. A signal that came in that moment left the handler,

  waits between polls sleep in steps of at most a second, so a stop is acted on within a second.

  stuck in its signal handler".

  mechanism, not the rate.
